8Serial port interface for Linux, macOS and Windows, C++20.
9The class is a thin, RAII wrapper over the native port handle: it never
10busy-waits, it buffers input internally, and it restores the original port
11settings on close. Line framing, timeouts and buffering are implemented once,
12on top of a small platform layer (termios plus poll(2) on POSIX, DCB plus
13COMMTIMEOUTS on Windows).
14*/
